Mokopane Artisan Bakery &amp; Deli ( A responsive website developed  by Thapelo Daniel Manyama  for Mokopane Artisan Bakery &amp; Deli, showcasing its bakery products, services, business information and contact details.) 
The Mokopane Artisan Bakery & Deli website is a responsive website developed from scratch by Thapelo Daniel Manyama. The purpose of this project is to establish a professional online presence for Mokopane Artisan Bakery & Deli by showcasing its bakery products, services, business information and contact details.
The website was developed progressively through three different stages, starting with basic HTML structure and gradually incorporating CSS styling, JavaScript functionality, interactive features and animations.
This project demonstrates my growth and practical understanding of front-end web development, as well as my ability to transform a basic HTML webpage into a functional, interactive and visually appealing website.
Development Journey
Part 1: HTML Structure and Foundation( Due 14/08/2026 )
The first stage focused on developing the website from scratch using HTML (HyperText Markup Language).
At this stage, the website consisted primarily of HTML code, which provided the basic structure and content of the different webpages.
The main focus was on:
Creating the foundation and structure of the website.
Organising content using appropriate HTML elements.
Adding headings, paragraphs, images and navigation links.
Creating different sections to display the bakery's information.
Establishing the basic layout and structure of the website.
Although the website was still basic, Part 1 provided the foundation for all the improvements introduced in the following development stages.
Started Work on part 2 on the (26/08/2026)
Part 2: CSS Styling and Website Presentation ( Due 18/09/2026)
In Part 2, I started bringing the website to life by introducing CSS (Cascading Style Sheets).
The main objective was to improve the website's appearance, presentation and overall user experience. CSS allowed me to move beyond a basic HTML structure and create a more professional and visually appealing design.
Some of the CSS properties and styling techniques I implemented include:
Font Family: Selecting appropriate font styles to improve readability and maintain a consistent appearance.
Font Size: Adjusting text sizes to create a clear visual hierarchy between headings, paragraphs and other content.
Font Weight: Using different font weights to emphasise important information and improve presentation.
Colour Styling: Introducing suitable colours to create a visually attractive and consistent design.
Spacing and Layout: Applying margins, padding and other layout properties to organise content properly.
Image Styling: Improving the presentation and positioning of images throughout the website.
Responsive Design: Making the website adaptable to different screen sizes and devices.
This stage played an important role in transforming the website from a simple HTML project into a more attractive and organised digital platform.
Started Working on Part 3 (28/09/2026)
Part 3: Final Portfolio of Evidence – JavaScript and Deployment (Due 02/11/2026)
Part 3 marked the final stage of development, where I focused on making the website more interactive and functional by implementing JavaScript.
JavaScript introduced dynamic features that improved user interaction and made the website feel more complete.
The additional functionality included:
1. Interactive Navigation and Welcome Messages
I implemented JavaScript functionality that displays a welcoming message when visitors interact with the About Us page. This creates a more engaging experience and makes the website feel more interactive.
2. Interactive Website Sections
I improved the Menu, Services and About Us sections to make the website easier to navigate and allow visitors to explore the bakery's information and offerings.
3. Image Lightbox Functionality
One of the interactive features I implemented is the Lightbox effect. When a visitor clicks on an image, the image opens in an enlarged view, allowing them to see the details more clearly without leaving the webpage.
4. Website Animations
I introduced animations and visual effects to improve the overall appearance of the website and create a smoother browsing experience.
5. Website Deployment
After completing the development process, I deployed the website using GitHub Pages, making it accessible online.
This final stage brought together HTML, CSS and JavaScript to produce a complete and interactive website.
